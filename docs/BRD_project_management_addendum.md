# ملحق BRD: إدارة المشاريع الاستراتيجية والجودة

## الوصف

يوفر النظام وحدة متكاملة لإدارة المشاريع الخاصة بالاعتماد الأكاديمي والجودة والتحسين المؤسسي، بحيث يتم التعامل مع كل مشروع ككيان مستقل يحتوي على خطة تنفيذية، مراحل، مهام، فرق عمل، مؤشرات تقدم، ومتابعة زمنية.

## 1. إدارة المشاريع

- إنشاء مشروع جديد.
- تحديد اسم المشروع، نوع المشروع، الجهة المالكة، البرنامج أو الكلية، تاريخ البداية والنهاية، الأولوية، وحالة المشروع.
- دعم أنواع المشاريع التالية:
  - مشروع اعتماد أكاديمي.
  - مشروع اعتماد برامجي.
  - مشروع تحسين جودة.
  - مشروع استيفاء شروط.
  - مشروع دراسة ذاتية.
  - مشروع تطوير برنامج.
  - مشروع قياس مخرجات تعلم.
  - مشروع خطة تشغيلية.

## 2. إدارة المراحل

- إنشاء مراحل لكل مشروع.
- تحديد اسم المرحلة، تاريخ البداية، تاريخ النهاية، نسبة الإنجاز، والمسؤول.
- أمثلة المراحل: إعداد الدراسة الذاتية، جمع الأدلة، المراجعة الداخلية، الزيارة التجريبية، الرفع لجهة الاعتماد، معالجة الملاحظات، الإغلاق النهائي.

## 3. إدارة المهام

- إنشاء مهام ومهام فرعية.
- تحديد المسؤول، الأولوية، الموعد النهائي، الحالة، والاعتماديات.
- حالات المهام: New، In Progress، Pending Review، Completed، Delayed، Cancelled.

## 4. إدارة الخطة الزمنية

- إنشاء مخطط Gantt.
- متابعة الجدول الزمني.
- مقارنة Planned vs Actual.
- متابعة التأخير.
- تنبيهات المواعيد الحرجة.

## 5. إدارة الموارد والفرق

- توزيع فرق العمل.
- تحديد مدير المشروع، أعضاء الفريق، المراجعين، والمستشارين.
- توزيع المهام حسب الصلاحيات، الخبرات، واللجان.

## 6. مؤشرات الأداء والمتابعة

- قياس نسبة الإنجاز.
- قياس عدد المهام المتأخرة.
- قياس نسبة استيفاء المتطلبات.
- قياس نسبة اكتمال الأدلة.
- توفير Dashboard للمشاريع.

## 7. إدارة المخاطر والقضايا

- تسجيل المخاطر.
- تسجيل القضايا.
- إعداد خطط المعالجة.
- تحليل الأثر.
- مسار تصعيد للمخاطر والقضايا.

## 8. التنبيهات والإشعارات

- تنبيهات المهام المتأخرة.
- تنبيهات اقتراب المواعيد.
- إشعارات اعتماد المهام.
- إشعارات الملاحظات الجديدة.
- دعم قنوات Email / SMS / In-System.

## 9. التعاون والتواصل

- التعليقات على المهام.
- مشاركة الملفات.
- الاجتماعات ومحاضر الاجتماعات.
- Activity Timeline.

## 10. التقارير التنفيذية

- تقرير حالة المشروع.
- تقرير الإنجاز.
- تقرير التأخير.
- تقرير المخاطر.
- تقرير استهلاك الوقت.
- Executive Dashboard.
